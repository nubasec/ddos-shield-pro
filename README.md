# DDoS Shield Pro

Plugin WordPress para protección básica contra abuso de solicitudes, intentos de fuerza bruta, bloqueo temporal de IPs, alertas administrativas y monitoreo de eventos.

## Funcionalidades

- Rate limit por IP.
- Protección de login por intentos fallidos.
- Dashboard administrativo moderno con identidad Nubasec.
- Exportación CSV segura.
- Alertas HTML por correo con limitación de frecuencia.
- Whitelist de IPs y CIDR IPv4.
- Soporte opcional para proxies confiables y `X-Forwarded-For`.
- Geolocalización externa desactivada por defecto.

## Recomendación

Este plugin no reemplaza un WAF perimetral. Úsalo como una capa adicional de monitoreo y control dentro de WordPress.
